## 2. 池的构造(在看到任何分数之前定死)

每个 spec 的候选按 `sha256(spec_id + "\0" + image_path)` 排序。

## 3. 估计量

分数近似连续但落在 bf16 网格上,并列仍可能发生。按分数分组降序,
`m_j` 为第 j 组大小,`M_j` 为累计:

    P(第 j 组是子集中出现的最高组) = [C(K − M_{j−1}, N) − C(K − M_j, N)] / C(K, N)
    E[正确率 @ N] = Σ_j P_j × (第 j 组的组内正确率均值)

这与「子集内最高分并列集均匀选择」逐字同义(组内成员在子集中的出现是可交换的),
是精确值而非抽样近似,且为 O(组数)。**必须先在 `runs/v4/gate-b-openct2`(K=4/6)上
复现 `bon-coupling-20260908` 已验证的穷举结果,逐值相等才允许用于本轮;不等则本轮作废。**

同时精确计算 `oracle(N) = 1 − C(K−C, N)/C(K, N)`(C 为池内正确数)与最高分并列集期望大小。

`gain(N) = external(N) − external(1)`,按 spec 配对。区间为**以 spec 为单位**的
5000 次 bootstrap 95% 区间,种子 20260908。

## 4. 预先写死的判定规则

- **耦合成立**:`gain(N_max)` 的 95% 下界 > 0。每个队列分别判定。
- **转向(D\* 候选)**:令 `N_peak = argmax_N gain(N)`。转向确认需要
  `gain(N_max) − gain(N_peak)` 的**配对 bootstrap 95% 上界 < 0**。
  仅点估计回落不算转向。
- **无转向**:若 `N_peak = N_max`,写「未见转向,D\* > KL(N_max) nats」,
  这是下界,不是脱钩不存在的证据。**不得加算力、不得换评分器、不得改 N 阶梯来抢救。**
- **末段斜率**:报告最后两个 N 之间的 pp/nat,仅用于说明「离转向还有多远」,
  **不得外推出 D\* 的位置**。
- **失败条件**:§3 的估计量回归不通过;cycle 分数不可复现;任一 spec 的候选数与记录不符;
  workset 与 verified 记录对不上 → 本轮作废,证据原样保留,不部分发布。
