# BSV 的下游收益:盲验证比带 prompt 的自验证选出更好的图

2026-09-08。`bsv_selection.py`,零 GPU,纯读盘。
数据源:`runs/v4/main-2plus1` 与 `runs/v4/main-1plus1plus1` 的
`answers.jsonl`(image_only)与 `answers.prompted.jsonl`(prompted),
两个条件是**同一批图、同一批题**,只差上下文里有没有生成 prompt。

`context-ablation-20260908` 回答的是感知问题(盲 0.654 / 告知 0.336)。
这份回答生成问题:**多出来的那点感知,拿去当自改进回路的选择信号,值多少?**

---

## 主结果

选择规则:每个 prompt 的 K 张候选里,取「与 spec 一致率」最高的一张,
看它的外部正确率(`image_correct`,检测器阶梯 + 人工裁定过的)。
平局按均匀随机打破的期望值算,首索引打破的结果并列给出。

**能被选择影响的池(池内有对有错,134 池 / 514 图):**

```
random     0.417
prompted   0.549      <- 标准自改进回路
blind      0.654      <- BSV
oracle     1.000

blind - prompted  +0.106 [+0.062,+0.151]   符号检验 54:15, p=2.6e-06
```

换个说法更直观:自选择相对随机的收益,从 **+0.132 涨到 +0.237**,
**接近翻倍**。而且 BSV 的上下文更短(preamble 被删掉了),
推理成本不增反降,训练成本为零。

全部 225 池(含全对/全错、选择无能为力的池)上是 +0.063 [+0.036,+0.091]。

## 一个机制性的旁证

```
分数能区分开池内任意两张候选的比例:  blind 190/225   prompted 123/225
```

带 prompt 的自验证在近一半的池里**给所有候选打同一个分**。
它不是选错了,是**没有意见**——正是「prompt 条件下的确认器」该有的样子,
也和 `s_select` 判别 gap 在 32 步内塌到 0.000 是同一件事。

## 两个对照

**对照 1:是不是只是盲的分数粒度更细、平局更少?**
只看两种规则**都**能给候选排序的池(77 池):

```
prompted   0.623
blind      0.693
blind - prompted  +0.069 [+0.011,+0.130]   符号检验 19:7, p=0.029
```

缩小了,但没消失。所以差异来自**答案本身**,不是来自刻度分辨率。
(这个子集是按结果条件化选出来的,本身带选择效应,只能当辅助证据。)

**对照 2:只用非冲突题打分。**
在 spec 与像素一致的题上,上下文消融量到的是 0.979(盲)对 0.990(告知)
——prompt 是**帮忙**的。所以机制预测:去掉冲突题,选择增益应当消失。

```
random     0.420
prompted   0.410
blind      0.400
blind - prompted  -0.010 [-0.028,+0.007]   符号检验 12:18, p=0.36
```

**消失了,而且两种规则都掉到随机水平。** 非冲突题里根本没有「这张图错没错」
的信息。整个选择增益精确地落在冲突试次上——也正是上下文消融说感知被压过的地方。

这是一条完整的因果链,每一环都测过:

1. prompt 在上下文里 → 冲突试次上感知崩掉(−31.8 点,p=5e-54)
2. 冲突试次是唯一携带「这张图对不对」信号的题(对照 2)
3. 所以移走 prompt → 选出的图更对(+10.6 点,p=2.6e-06),且不是平局效应(对照 1)

## 必须写进论文的异质性

两个 corpus run 拆开看,**结论不一致**:

```
main-2plus1        prompted 0.464  blind 0.653   delta +0.190 [+0.128,+0.255]  p=3.4e-07
main-1plus1plus1   prompted 0.622  blind 0.655   delta +0.034 [-0.023,+0.093]  p=0.20
```

两个 CI 不重叠(z≈3.6),这是真异质,不是噪声。**不能只报合并值。**

但异质性的来源查清楚了,而且是机制内部的:

```
                     冲突题上的准确率
                     blind    prompted   上下文效应
main-2plus1          0.638     0.198       -0.440
main-1plus1plus1     0.667     0.453       -0.214
```

**blind 稳得出奇(0.638 / 0.667),波动全在 prompted 那一侧。**
也就是说:这两个 corpus 的差别不是「BSV 有时不管用」,而是
**「确认偏差本身的强度随 checkpoint 变化,差了两倍」**。
上下文效应大的那个 run,选择增益也大(−0.440→+0.190;−0.214→+0.034),
方向和量级都对得上。

两个点当然不叫剂量-反应。但主运行会给出 13 个 checkpoint × 2 arm 的点,
**「上下文效应强度 → 选择增益」应当画成一条散点回归**,
异质性从威胁变成论文的一张图。这条写进预注册。

## 两条必须写在正文里的限制

1. **题目是 detections 派生的**,选项里可能出现「实际画出来的东西」。
   真实回路只有 spec,会写出不同的干扰项。
   blind/prompted 的**对比**是公平的(同题、同图,只差上下文),
   但两个 arm 的**绝对水平都偏乐观**。要拿绝对数字,得用 spec-only 题重跑。
2. **这是一次事后选择的重放**,不是端到端训练。它说的是
   「同一批候选,换个打分方式能多选对多少」,
   不是「用 BSV 训练一轮之后模型变好多少」。后者是 arm B 要回答的。
