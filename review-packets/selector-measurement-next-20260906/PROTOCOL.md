# 固定图像上的提示词干预与否定原子开发诊断

2026-09-06。依据已看过的先导数据制定；本文件在新增回答产生前冻结。这不是独立确认实验。

本轮执行范围：现有固定 bank 的 16 池、80 张图片，不生成图片，不更新模型参数，不计算新梯度。
主分析沿用先前冻结的场景排除规则，保留与计划训练/replay 场景无重叠的 14 池；16 池完整结果并报。
14 池来自排除训练场景重叠，并非把 bank 内的 16 个独立场景去重成 14。

主研究对象为 Naive 训练臂。测共享 base、Naive16、Naive32；Gold16、Gold32 为匹配对照。
两条训练臂都用各自 Show-o2 checkpoint 作观察者。原 gate-b 表中的 rfo 是冻结 Qwen2-VL
观察条件，不能与 Gold 训练臂混称，也不把哪个条件表现好作为挑选主臂的依据。

每个 checkpoint、每张图都重新运行“提供原生成 prompt / 不提供原生成 prompt”。
题面仍由 spec 派生，所以后一条件只称去掉生成 prompt。保持同图、原题、选项顺序、图像 latent、
解码参数和权重一致；条件执行顺序按固定哈希平衡。使用新建请求，条件间不保留对话历史。
旧 prompted 回答只用于复现核验，不以旧回答替代新条件配对。先汇报差异，不隐藏不一致。

题目变体：原题逐字保留；追加由 spec 和冻结名词词表决定的否定存在题。名词规范化后剔除
该 spec 中所有已有类别，独立固定 RNG 无放回抽取，数量等于该 spec 原存在题数。
否定题的期望答案 no，A/B 顺序使用独立 RNG；不读取图片、检测或分数来挑否定名词。
同一 spec 的所有候选使用同题，不修改历史 spec_questions 或训练选择器。

旧评分按原题均分；变体评分按原题与追加题的总题数均分。另报三族分数：原存在、计数、
新否定存在，公开因题量增加带来的权重变化。模型从 prompt 推导所有期望答案仍可能满分，
因此该变体只检验额外物体覆盖及 yes 偏置，不预设它能解决提示词复述或评分并列。

外部整图标签沿用原已裁定 bank，完整图标签 80/80。题级事实使用已保存的完整裁定记录，
disputed_scope、unnameable 等保持未知，不把未知视为 absent。原题与新题分别固定可判集合，
所有 checkpoint/条件使用同一集合。全图标签不等于每道事实已知。人类整图裁定不扩写为物体列表。

固定输出：逐池实际选择收益（实际选中正确性减同池完整候选随机期望）、最高分并列大小、
并列集正确比例、同池基础率、最高分集合中没有正确图的池数、严格排序与同分情况。
同时报告全部池与仅有并列的池，按池等权，并列集合大小加权的微平均单列；不混用分母。
并列集正确比例是均匀并列决胜的条件期望，不是任意决胜规则的正确率上界。

观察指标分开报告“回答符合请求 / 回答符合事实 / 事实符合请求”；主要机制比较为原题中
事实与请求冲突的固定子集上，去掉 prompt 对事实准确率的影响。报告 Naive32-base 的
干预效应变化与 Gold 同步对照，不用 spec 符合度冒充观察准确率。

所有不确定性以场景为重采样单位，固定 5000 次、seed=20260906；本轮区间是先导描述，
不校正多重查看、不覆盖独立训练种子变异，不声明 D* 或 D_g。没有“Naive 必须优于随机”的
验收门槛：观察/选择失败本身是研究结果。运行验收要求输入/权重/题目绑定正确、请求完整、
未知显式报告、同条件原题复现差异可追踪，任何完整性失败先诊断。

后续独立场景设计的工作目标先固定为：Naive 原评分的选择收益变化 10pp，双侧 95% 区间
半宽不超过 5pp，并评估 80% 检出率所需场景数。这是本阶段选择器测量的精度目标，不是
原 D* 的 2pp 外部门槛。用多个配对变化率情形作 CPU 规划，不能只拿稀疏先导点估计保证功效。
本轮 16 池不能作为达到这一精度的验收集。正式规模/新场景冻结是结果报告后的下一项决定。

232 池是已观察的开发数据，只用来复核并列统计、计算否定题的覆盖上限，不称新的盲测。
人工需求按实际 unresolved 数报告；10% 是历史仪器要求，不是未来人工工作量的概率保证。
未来整图尽量完整裁定，仍无法判断的保留未知并给界，不强迫补标到零未知。

所有产物只写入本侧目录。原训练停在32步，旧题目、旧报告、checkpoint 与定时任务均保持原状态。
