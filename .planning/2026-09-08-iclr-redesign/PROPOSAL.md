# 重新规划:从「找分叉点」到「自我报告为什么是坏的监督信号」

2026-09-08。起因是一个判断:D* 一个点撑不起 ICLR,要补一个 D_g 一样的东西。
补 D_g 不解决问题,因为端点本身测不了(见 `review-packets/dg-power-20260908/`)。
下面重新规划,依据全部是今天在既有数据上实测出来的,没有新的 GPU 开销。

---

## 0. 一句话

原来的问题是「自我确认什么时候开始」(一个时间戳)。
新的问题是「**自我报告为什么从一开始就不是监督信号**」(一组对比量)。
后者已经有了强证据,且每个端点都是比例或比例之差,不是搜出来的拐点。

## 1. 让整件事翻转的那个发现

`s_select` 问模型:"Is there a white book in this picture? A. yes B. no",
按 `expected_answer` 打分,而 `expected_answer` 来自 **spec**——图里该有什么,
不是图里实际有什么。所以一个完全不看图、照 prompt 回答的模型得 1.0。

聚合分 94.7%,而这些图只有 31% 真的画对。按图的实际对错拆开:

```
arm       step  family     format          | img right  | img wrong     gap  n wrong
naive        0  existence  forced_choice         0.981        0.934  +0.047      106
naive       32  existence  forced_choice         1.000        1.000  +0.000       95
naive        0  count      open                  0.962        0.877  +0.084      106
naive       32  count      open                  0.984        0.895  +0.089       95
rfo_gold    32  existence  forced_choice         1.000        1.000  +0.000       99
rfo_gold    32  count      open                  0.983        0.899  +0.084       99
```

三件事同时成立:

1. **forced-choice 的判别力在 32 步内塌到恰好 0.000**,两个 arm 都是。
   模型对着一张错图,100% 确认 prompt。这就是自我确认,而且它是一个**对比量**
   (+0.047 → 0.000),不需要任何拐点。
2. **open format 的判别力没塌**(+0.084 稳住)。提问格式决定了信号存不存在。
3. 按失败模式拆(naive/step-32):**物体在图里完全不存在时(n=33),
   模型仍有 95.2% 说「有」**。这是可能存在的最容易的感知判断。

对照:内隐信号还活着。cycle 分预测外部正确性的 AUC 是 0.832 → 0.887(上升),
`can_it_see.py`。但这是跨 prompt 的 AUC,被 prompt 难度混淆——同一个 prompt
内部多次采样之间能不能判别,是主运行(R=4)才能回答的。

## 2. 这个结论目前的硬缺口(必须先补,而且最便宜)

**158 道 existence 题的 `expected_answer` 全部是 "yes",模型 158 次全答 "yes"。**
这个探针在构造上无法区分「读图」和「一律说 yes」。count 题稍好,但模型答案分布
(1:120 / 2:37)几乎精确复制 prompt 分布(1:124 / 2:34)。

**从来没有人问过一个正确答案是「没有」的问题。** 在补上之前,
「模型在背 prompt」是强烈提示,不是已证事实。这是 E1 的核心。

## 3. 为什么原来的估计量必然失败(设计教训)

| 端点类型 | 例子 | 实测精度 |
|---|---|---|
| 搜出来的拐点 | D* | knot SD 11.3 步 / 88 步跨度,正确格点命中率 29.8% |
| 两个拐点之差 | `Lead` | SE 16–18 步,需真值 > 35 步;12→24 ck 只从 11.4 到 11.0 |
| 比例之差 | 外部正确率 | SEM 0.0150(R=4,64 题),5 个点的差 = 3.3σ |
| 配对的逐项对比 | s_select gap | SEM 0.016–0.022,+0.047 → 0.000 清晰可见 |

**差了一个数量级。** 新规划的每个端点都落在下面两行,不落在上面两行。

## 4. 分解:自我改进这条链在哪一环断掉

```
coverage --> perception --> selection --> distillation --> gain
```

| 环节 | 定义 | 现状 |
|---|---|---|
| Coverage(K) | K 次采样里至少一张满足 spec 的比例 | 主运行 R=4 直接产出,免费 |
| Perception | 能否在自己的样本里分辨对错 | 外显:gap 0.000(塌了);内隐:待测 |
| Selection | 有对的时候能否选中 | Self-best-of-K vs Oracle-best-of-K |
| Distillation | 训练能否向选中的样本移动 | 31% → 37% / 32 步,两 arm 只差 4–6/64 题 |

四个数都是比例,n = 64 × K,SE 约 2–5 个百分点,**没有一个需要拐点**。
它们相乘/相减就把总缺口分配到了具体环节——这是论文的主图。

## 5. 三个实验

### E1 感知审计:换掉验证语境,不训练(核心贡献,零训练成本)

同一批已经存在的图,四种提问语境,端点是「对图 vs 错图」的判别 gap:

| 语境 | 目的 |
|---|---|
| (a) forced-choice + prompt 在上下文里 | 现状基线 |
| (b) **正确答案为「没有」的题** | 排除 yes-bias,§2 的硬缺口 |
| (c) open-ended 描述,prompt 不在上下文 | 去掉 prompt 先验 |
| (d) forced-choice + **另一个 spec 的 prompt** | 直接测「答案来自 prompt 还是像素」 |

(d) 是判决性的:如果模型对着同一张图,跟着替换的 prompt 改答案,
那么自我报告就是 prompt 的函数,不是图像的函数。

成本:纯推理。64 题 × 4 draw × 4 语境 × ~5 问 ≈ 5000 次前向,单卡数小时。
**这一个实验就能独立支撑一篇论文,而且不依赖任何正在跑的东西。**

### E2 分解:在主运行上算 §4 的四个数(免费)

`images_per_outcome_prompt: 4` 已经在跑。跨 12 个 checkpoint × 2 arm,
给出 Coverage(4) / Oracle-best-of-4 / Self-best-of-4 / 训练后实际值的轨迹。
额外好处:**同一 prompt 内的 4 张图之间做判别**,这是唯一不被 prompt 难度混淆的
内隐感知测量,pilot(R=1)做不到。

### E3 干预:用 E1 里最好的语境替换自选择,重训一个 arm

端点是最终外部正确率的**差**,不是拐点。成本约 26 h 单卡。
如果 E1 显示 (c) 或 (d) 恢复了判别力,E3 就是方法贡献:
**统一模型的自我改进可以靠解耦验证语境来修,而不是靠更大的 verifier。**

### 可选:跨模型规模的复制(纯推理)

Show-o v1 / Show-o2-7B 是冻结负对照。**只做推理侧的感知审计属于对照用途,
不是提回主线**,但这一步要先经你确认再动。

## 6. 论文的主张

> 统一模型里,"verifier" 和 generator 是同一套权重,且判断时 prompt 就在上下文里。
> 所以它不是自己输出的独立验证者,而是一个 **prompt 条件下的确认器**。
> 自我报告的判别力在 32 步训练内塌到 0.000,而同一时间内隐信号仍在上升——
> 说明信息还在模型里,只是外显报告通道被 prompt 先验占据了。
> 解耦验证语境可以把它取回来。

这个主张是机制性的、可证伪的、有干预的,而且每个端点都可测。
