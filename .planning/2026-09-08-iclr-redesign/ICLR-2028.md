# 这份工作能不能进 ICLR 2028

**2026-09-08 写,在 E3 与 E4 产出任何数字之前。**
所以下面凡是关于结果的话都写成条件式:哪个结局对应哪个判断,先定死,
免得看到数字之后再挑一个说法。这本身也是预注册纪律的一部分。

时间不是约束。按 ICLR 近年的节奏,2028 的截稿大约在 2027 年 9 月,
从今天算还有十二个月。**这十二个月能不能用来补第二个 seed,
是决定这篇能不能上主会的单一最大变量**,详见 §5。

---

## 1. 一句话

**核心测量足够强,足够干净,也足够反直觉,可以支撑一篇 ICLR 主会论文——
但它现在只是一个感知现象加一个离线重放。这篇能不能上,取决于 E3 端点 1
是否证明它在训练回路里真的改变了模型,以及能不能拿出第二个 seed。**

结局 A 全中,我判断是主会有戏、但会被审稿人在 seed 上按住的一篇。
结局 B(端点 1 null),按预注册收缩后是一篇扎实的 workshop 或次级会议论文。
结局 C(端点 2 里 B 也塌),机制被证伪,主会基本无望,但仍是一个值得写的负结果。

## 2. 已经握在手里的(冻结,不依赖任何还没跑的东西)

**上下文消融**(`review-packets/context-ablation-20260908`)。
在图与 spec 冲突的试次上,**同一个 backbone、同一张图、同一道题**,
唯一差别是生成 prompt 在不在上下文里:

```
盲     0.654 [0.617, 0.689]  n=667
告知   0.336 [0.301, 0.372]  n=682
配对精确 McNemar 221 : 9,p = 5.12e-54
```

这不是一个「显著但小」的效应,是**准确率被翻转到低于随机**。
221 比 9 的不对称几乎不需要统计:去掉描述答对、加上描述答错的试次,
比反过来多二十多倍。

**下游收益**(`review-packets/bsv-selection-20260908`)。
在 K 张候选里按自评一致率选一张,看外部正确率:

```
random    0.417
prompted  0.549    <- 标准自改进回路
blind     0.654    <- BSV
blind - prompted  +0.106 [+0.062, +0.151]   符号检验 54:15, p=2.6e-06
```

自选择相对随机的收益从 +0.132 涨到 +0.237,**接近翻倍**。
这一步是把「感知上的怪现象」变成「关于自改进的结论」的关键,
没有它,前面那个 0.654/0.336 只是一个 VLM 的行为观察。

**仪器纪律。** 这一项在评审里通常不加分,但一旦被挑就极贵,而这里是干净的:
gold 取自图不取自 spec;冲突试次单独隔离;配对键是 (image_path, question);
预注册带偏离日志;评分器有变异测试,而且改评分器时用全部 7246 条冻结行
证明了一条都没动。审稿人往下挖是挖得住的。

## 3. 还没有的,以及它决定什么

| 缺的东西 | 它决定 |
|---|---|
| E3 端点 1:B 的最终外部正确率 − A 的 | 论文能不能声称「BSV 改进生成」,而不只是「改进选择」 |
| E3 端点 2:s_select 判别 gap 的斜率 | §2 的机制解释成立还是被证伪 |

端点 1 的可测下限**在看结果之前就写死了**:配对比例差的 SEM ≈ 0.0150,
80% 功效对应 +0.042。点估计小于它且 CI 含 0,就判未测到,不许换口径抢救。
这条写在预注册里,对论文是加分——它意味着 null 也是一个可报告的结果,
而不是一次失败的实验。

## 4. 三种结局

### 结局 A:端点 1 正、端点 2 里 A 塌 B 不塌、E4 复制 2/3

故事是完整的:**测量**(0.654/0.336)→ **机制**(判别 gap 在带 prompt 的
自验证下塌成 0,去掉 prompt 就不塌)→ **后果**(自改进回路的最终模型更好)
→ **普适性**(跨规模、跨家族)。而干预是零训练成本的。

这是 ICLR 主会论文的形状。我判断**有实打实的机会**,但不是稳的:
见 §5 的 seed 问题。

### 结局 B:端点 1 未测到,其余成立

按预注册收缩为「BSV 提升选择信号质量」,主张退回推理期。
离线重放已经支持这一条,E4 给它范围。
这仍然是一篇有内容的论文——**「统一模型的自验证其实是确认」这句话本身
就有价值**——但它失去了「所以自改进回路会更好」这个后果。
我判断:ICLR 主会**边缘偏下**;workshop 或次级会议**稳**。

### 结局 C:端点 2 里 B 也塌

§2 的机制解释被证伪:去掉上下文不足以阻止感知在训练中被吃掉。
必须在正文写明。这是一个诚实且不常见的负结果,
但「我们提出的免费修复不管用」很难在主会拿到接收。

## 5. 最大的拒稿风险:单 seed,而且它现在是可以买的

预注册 §4.2 已经把它写成 limitation:**单 backbone、单 seed**。
E4 处理规模和家族,但**只处理推理期那一半**——训练期的主张(端点 1、端点 2)
全部压在一个 seed 的一条轨迹上。

这是自改进 / RL 类论文最标准的拒稿理由,而且审稿人说得有道理:
一条曲线上的拐点和斜率,在 seed 之间的抖动经常和效应本身同量级。
项目自己的数据就是证据——`dg-power-20260908` 测出拐点估计量的 SD 是 11.3 步,
而整个训练跨度只有 88 步。**项目已经在拐点类量上被 seed 噪声打败过一次**,
论文却要在同样单 seed 的比例类量上下结论。

预注册当时的理由是「算力预算里没有第二个 seed」。**在十二个月的窗口下,
这个理由不成立了。** arm B 的配对跑约 52 小时;第二个 seed 是再 52 小时。
一百多个 GPU 小时换掉这篇最可能的拒稿理由,是这份计划里边际价值最高的一笔。

**我的建议:把第二个 seed 从「预算外」改成计划内,现在就写进日程,
而不是等审稿人问。** 这需要你拍板,因为它改的是预注册当时的成本判断,
不是改预注册本身(§E3 没有禁止加 seed,禁止的是「Gate C 红之后加 seed 抢救」——
事前加和事后救是两回事,后者仍然禁止)。

## 6. 其余会被打的点,以及我认为该怎么应对

1. **「这不就是文本先验压过视觉吗?已知现象。」**
   最可能出现、也最致命的一句。应对不是辩解效应新,而是把落点放在
   **它发生在自改进回路的验证者位置上**:模型被当作独立验证者用,
   而它在结构上不可能是——权重共享,而且 prompt 还在上下文里。
   这句话要在 abstract 的第二句就出现,不能等到第 5 节。

2. **「BSV 不是方法,是删掉一段文本。」**
   预注册 §4.3 已经承认。贡献必须写成「测量 + 机制 + 后果」。
   干预的简单性其实应该当成卖点写:零训练成本、零参数、任何统一模型都能立刻用。
   但这只有在端点 1 为正时才立得住——否则「免费」修的是一个没有后果的东西。

3. **「题目是 detections 派生的。」**
   预注册 §4.1 已经分列。建议再加一步:对冲突试次抽一个人工核验的子集
   (几百条,人力可承受),把「gold 来自检测器阶梯」这条从 limitation
   降成一个有数字的稳健性检查。这比任何辩解都便宜。

4. **「1.5B 太弱,好模型不会犯这个错。」**
   E4 的 7B 腿就是答案。如果 7B 不复制,主张必须收缩成「小模型上出现」,
   这条预注册已经写死了不许靠加模型抢救。

5. **权重共享那一半有没有被测?** 有。
   三个臂给出 2×2 的三格:naive(自己看 + 告知)、blind_self(自己看 + 不告知)、
   rfo_gold(外部看 + 不告知)。A vs B 是上下文主效应,B vs C 是权重共享主效应。
   只缺交互项那一格(外部看 + 告知)。这是一个可辩护的设计,不是缺口,
   但**正文要把这张 2×2 画出来**,否则审稿人会以为只测了一个因子。

## 7. 结论

**值得做完,而且现在的证据基础比大多数投稿在这个阶段要扎实。**

但把它当成一篇稳的 ICLR 主会论文来规划是自欺:
它现在缺的不是打磨,是两个还没跑出来的实验结果和一个还没决定要不要买的 seed。
E3 端点 1 是分水岭——正,就按结局 A 全力写;
未测到,就按预注册老老实实收缩,不要在那一步上花时间抢救。

### 更正:第二个 seed 的价码不是 52 h,是 80 h 上下

**这个估计已经被实测推翻。** 主运行 09-09 01:2x 时跑了 17.5 h,只完成 11 轮里的
第 1 轮;按第一个评测块外推 76 h,按第二个(慢 31%)外推 88 h,详见

所以实际价码是**每个额外 seed 约 76–88 h 墙钟、两张卡各占满**,即 150–180 GPU 小时,
不是「一百多」里偏低的那头。**结论方向不变**——它仍然是这份计划里边际价值最高的
一笔支出,拿掉的是最可能的拒稿理由。但排期上要看清楚:一个 seed 就是三天半,
而且预注册的墙钟上限是每次运行 96 h(偏离 5),两个 seed 排不进同一个星期。

**这件事从 09-08 挂到现在还没拍板,它是本计划里唯一一个在等人的决定。**

## 9. 裁定(2026-09-09,用户拍板,不改写上文)

**全程单 seed。第二个 seed 不买,更多的也不买。**

§5 建议把第二个 seed 从「预算外」改成计划内,§8 把价码从 52 h 更正到 76–88 h
并记为「本计划里唯一一个在等人的决定」。这条建议**被否决**。上文两处原样保留:
它们是当时的判断和当时的价码,不是错的,只是没有被采纳。

### 这不是偏离,是回到预注册

`PREREG.md` 两处本来就写死了单 seed:§4.2 第 2 条「单 backbone、单 seed……
项目的算力预算里没有第二个 seed,这条如实写进 limitations」,以及 E3 的
「无论结果如何都不做:不加 seed / 不加算力 / 不换 backbone 去抢救」。
§5 想改的是前一条的**成本前提**,不是禁令本身。既然不改,**没有偏离要登记,
`PREREG.md` 一个字不动**,偏离 1–5 之后不新增第 6 条。

顺带把一件事说清楚:这条裁定同时消掉了 §5 留下的一个灰区。原文区分了
「事前加 seed」与「Gate C 红之后加 seed 抢救」,说前者不被禁。现在两者都不做,
将来也就不存在「这算事前还是事后」的争论——**任何时点提议加 seed 都是推翻本节,
必须先写明推翻的理由并追记,不得默默开跑**。

### 代价照写,不粉饰(本小节 2026-09-09 当日重写,见文末「修订记」)

§5 说的拒稿风险一分不减:E3 端点 1、端点 2 的全部训练期主张压在一条轨迹上,
run-to-run 这个方差分量我们没有估计。这一点必须在 limitations 里用这句话
正面写出来,不许用「due to computational constraints」一笔带过。

**但对「你只跑了一个 seed」这句审稿意见,我们的回答不是「预注册事前就这么写的」。**
那是程序性辩护,而程序性辩护在审稿里几乎没有分量——它回答的是「你有没有作弊」,
不是「你的结论站不站得住」。我们手上有一个实质性的回答,而且它已经是真的:

1. **再跑一个 seed 不是审稿人想象中的那个修复。** n=2 只给出一个差值,
   方差估计 df=1;要撑得起「换个 seed 也这样」,量级在 5 个以上,即 380–440 h。
2. **本项目量过小 n 的 seed 区间会撒谎。** 已注册的 `paired_bootstrap_lead`
   对 3 个值做 bootstrap,报出的「95% CI」就是那 3 个值的极差,I 类错误 9.5%
   (名义 5%)。这正是我们放弃拐点类端点的原因之一。
3. **对被放弃的那类估计量,加 seed 也救不回来**:3 个 seed 只把 Lead SE
   从 17.3 压到 10.0,仍是 88 步跨度的 11%。
4. **我们保留的那类估计量,主导方差分量不在 seed 上,而在 prompt 上,
   并且被量化了**:实测配对 SEM 0.0150,事前写死可测效应 +0.042。

合起来是一句话:**我们没有回避 seed 这个方差分量,我们量化了它在这条流水线上
的行为,并因此换掉了端点。** 「事后没有加 seed 去救」仍然值得说一句,但它是
这段话的脚注,不是主句。

**一处措辞必须改掉,连带 §5 和 §8 也一起认。** 上文(以及本小节的旧版本)
写「`dg-power-20260908` **测出**拐点类估计量 SD 11.3 步」,读起来像是跑过多个
真实 seed。**没有。** 那是一次蒙特卡洛:真 Lead 人为设成 0 / 16 / 32、每个条件
400 次重复,噪声水平用实测 SEM 标定。**噪声是实测的,knot SD 与 Lead SE 是
模拟出来的。** 结论不变(分辨率不够在两种读法下都成立),但论文里写错就是编数据。
已登记为 `PREREG.md` 偏离 6.3:引这批数字一律写 "calibrated simulation",
不得写 "we observed across seeds"。§5 与 §8 的原文按惯例不改写,以本条为准。

### seed 轴没了,承重换到哪两处

正文必须把这两处和 seed 复制**显式区分开**,不许含混:

1. **E4 跨模型复制**(注册的三个模型:`showo2_1p5b` / `showo2_7b` / `showo_v1`)。
   它是横向复制,证的是「这个现象不止一个 backbone 有」,**不证**「同一个
   backbone 换个 seed 也这样」。§5 已经说过 E4 只覆盖推理期那一半,这条不变。
2. **prompt 级配对推断**。分析单位是 prompt 不是 seed:132 个 prompt 上的
   配对比较,是对**这一次运行**的合法推断,n 来自 prompt。它同样**不支持**
   跨 seed 的稳健性主张。

### 由此收紧的四条写法(可执行,将来能被抓住)

1. 任何「arm X 优于 arm Y」的句子都要带作用域:**在这一次运行、这批 prompt 上**。
   没有作用域的比较句一律算 §8 第 3 条第四件事(把单 seed 轨迹写成显著性结论)。
2. **不报任何会被读成 seed 稳健性的误差棒或 CI。** 误差棒只能是 prompt 级
   bootstrap,图注写明「prompt-level, single seed」。
3. 拐点类量(D\*、D_g、Lead)因 SD 11.3 步已降为附录仪器负结果——单 seed 裁定
   让这条**永久化**,不得因为哪条曲线好看就提回主线。
4. §7 那句「一个还没决定要不要买的 seed」**作废**:已经决定不买。
   §7 的其余判断不变,结局 A/B/C 的判据不因本节改变。

**第 2 条已核对,仪器本来就合规。** `v4_decoupling_report.py` 报的区间
`ci_method` 是 `paired_spec_percentile_bootstrap`——重采样单位是 spec(prompt),
不是 seed;那里的 `seed=20260905` 是 bootstrap 的 RNG 种子,和训练 seed 无关。
所以不需要改代码,需要改的只是图注和正文措辞。
