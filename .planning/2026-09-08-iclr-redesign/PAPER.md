## 标题方向

**统一模型能看见自己画的东西,直到你提醒它本来要画什么。**

## §1 现象(已测,零 GPU,`review-packets/context-ablation-20260908/`)

同一批图、同一批题,按**像素**打分而非按 spec 打分。在 spec 与像素冲突的
判决性试次上:

```
image_only  0.654 [0.617,0.689] n=667
prompted    0.336 [0.301,0.372] n=682     delta -0.318
```

配对精确 McNemar:**221 : 9,p = 5.1e-54**。
counting 家族 0.824 → 0.256(−56.8 点)。

对照排除「prompt 让它分心」:在 spec 与像素一致的试次上 prompt 是**帮忙**的
(0.979 → 0.990)。prompt 不是噪声,它**恰好在冲突时压过感知**。

再加一条动力学:生成训练把这个缺陷推到极致。`s_select` 的判别 gap 在 32 步内
从 +0.047 塌到 **0.000**,两个 arm 都是。**缺陷在初始化就存在,训练把它变成彻底的。**

## §2 机制

统一模型里 verifier 和 generator 是同一套权重,**而且验证时生成用的 prompt
还在上下文里**。所以它不是自己输出的独立验证者,是一个 **prompt 条件下的确认器**。
生成训练加强 prompt→内容 的先验,而那正是让确认器不去检查的先验。

**这解释了为什么「感知提升生成」这条协同进化路线会自我抵消:
被训练的那个方向,恰好在腐蚀它依赖的那个信号。**

## §3 后果

所有统一模型的自我改进回路,验证时都把 prompt 放在上下文里(`s_select` 就是)。
所以它们在 **33.6%** 的感知准确率上运行,而 **65.4%** 本来免费可得。
监督信号在被使用之前就已经被污染,污染源可以直接去掉。

## §4 方法

**BSV(Blind Self-Verification,推理期,零训练成本)**
自我验证时把生成 prompt 移出上下文,只问图。已测收益 +31.8 点。

**CCR(Context-Consistency Regularization,训练期,完全自监督)**
惩罚「带 prompt」与「不带 prompt」两种语境下答案分布的散度。
不需要外部标注,不需要检测器——目标是**不变性**,
而任何对 prompt 的依赖按构造就是虚构。

**协同回路**:交替 (a) 在 BSV 选出的样本上做生成训练,(b) 对模型自己的输出做 CCR。
主张:这让感知和生成一起变好,而不是感知被吃掉。

## §5 协同进化实验(这是方法学论文的主实验)

三个 arm,同预算:

| arm | 选择信号 | 说明 |
|---|---|---|
| A `prompted-self` | prompt 在上下文里 | 标准回路 = 正在跑的 `naive` |
| B `blind-self` | prompt 移出上下文 | **本文方法** |
| C `oracle` | 外部 gold | 天花板 = 正在跑的 `rfo_gold` |

两个端点,都是比例,**没有拐点**:

1. **生成**:最终外部正确率。预测 B > A,且 B 补上 A→C 缺口的可测比例。
2. **协同**:每个 checkpoint 的盲测判别 gap。预测 A 塌到 0.000(已观测),B 不塌。

第 2 个端点就是「生成和感知能不能协同进化」的直接回答,而且是逐 checkpoint
的一条曲线,不是一个时间戳。

成本:A 和 C 正在跑,**只需要加 B 一个 arm,单卡约 26 h。**

## §6 泛化

原则不是关于图像的:**与生成器共享上下文的验证者不是独立验证者。**
它预测同样的失败会出现在文本自我批评、代码自我审查、任何把原始指令留在
上下文里的 self-refine 回路中。这是一个在本文领域之外可证伪的预测。
