# v2.3 RFO-Gold Gradient Gate Diagnosis

## Outcome

The local v2.3 gradient survival gate is **red because the fixed K=4 probe does not supply enough
informative candidate pools**. This is not evidence that the RFO-Gold correction direction is absent,
and it does not authorize three-seed training, A800 migration or a model change.

The run used only the existing `showlab/show-o2-1.5B-HQ` revision
`d3a220ec55feaacbdfcb053847edee14edd4e69a`, with GPU0 holding the trainable/gradient instance and
GPU1 holding a frozen step-0 observer. No model download occurred.

## Locked gate result

- Scheduled probe: 96 prompts, three independent repeats.
- Required common informative pools: at least 64 in every repeat.
- Fail-closed point: 42 prompts screened, 9 informative, 54 remaining.
- Optimistic maximum: `9 + 54 = 63`, so the 64-pool floor became mathematically unreachable.
- The second and third repeats and all short-curve training were therefore not run.
- Informative pools by family: existence 6/16 screened, color 2/13, spatial 1/13.

The evidence audit validates 42 atomic packets, 168 unique K=4 candidate records and RGB hashes,
three aligned selector logs, and 168 RGB/question-only frozen-observer requests. No request contains
the source prompt, generator state, selector label or other forbidden context. The v2.3 visible
questions/prompts contain no `square` wording.

## Small-sample diagnostic (not a gate pass)

The nine available informative pools were retained only to diagnose whether the implementation can
produce a Gold-specific update direction:

| Quantity | Result |
|---|---:|
| Identical-selection gradient cosine | 1.000 |
| Naive vs RFO-Self gradient cosine | 1.000 |
| Naive vs RFO-Gold gradient cosine | 0.274 |
| Naive/RFO-Gold gradient norm ratio | 0.758 |
| Naive/RFO-Gold selection agreement | 0.444 |
| Gold selected-score advantage | +0.25 (8 finite comparisons; 9 informative pools) |
| Split-half cosine interval | [-0.082, 0.322] |

The exact identical control confirms the fixed flow-noise/LoRA-dropout implementation. Naive and
RFO-Self are also identical at step 0, as expected when both observe with the same frozen backbone.
Gold changes both the selected RGB target and the gradient direction. However, the Gold cosine lies
inside the very wide nine-sample split-half interval, so the diagnostic cannot establish stable
separation or predict a training advantage.

## Interpretation and next registered change

The immediate bottleneck is candidate construction, not GPU memory and not yet the correction loss.
Random K=4 pools from this HQ model are usually all correct, all incorrect or insufficiently parsed
on the single primary atom. Filtering such pools after generation cannot yield a 64--128 item Gold
probe reliably.

A future, separately named revision should preserve this red result and preregister a bounded
candidate-bank search. For example, generate a deterministic bank of 12--16 same-prompt candidates,
then expose exactly four to every selector (two verifier-correct and two verifier-incorrect where
available). Search seeds must be disjoint from gradient/dropout seeds, the bank-size/search cap must
be fixed before viewing new gradients, and failure to assemble at least 64 balanced K=4 pools must
remain a hard stop. Only after that probe clears should the Base/Naive/RFO-Self/RFO-Gold short curves
run.
