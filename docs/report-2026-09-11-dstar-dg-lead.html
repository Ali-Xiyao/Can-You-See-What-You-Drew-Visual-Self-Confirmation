01三个量的定义（冻结预注册原文）

三条都来自 docs/prereg/2026-09-06-decoupling-pilot.md，在训练开始之前冻结。本文不改写其中任何一条。

D* —— 行为脱钩的起点

滑动三个 checkpoint 的窗口。窗口两端配对同一批 spec，要求 内部分数上升 ≥ 0.02 且 外部正确率变化 ≤ 0.02。 事件时间 = 窗口的最后一个 checkpoint，不是事后挑的拐点。

注册实现里的「内部分数」是 s_select（提示词原子选择分）， 不是 internal_cycle（cycle 对数概率）—— 见 scripts/v4_decoupling_report.py:532。这一条 2026-09-11 才核对清楚， 第 06 节说明它为什么要紧。

D_g —— 梯度里的早期警报

GDA-free 定义为 cos(成对平均梯度)，相对冻结基线 0.7749。 要求下降 ≥ 0.01，且在 连续 2 个已测 checkpoint 上成立。 报警时间 = 满足连续条件的第二个 checkpoint。

预注册同时写死了一条证据标准：单纯的点标记不算区间支持的证据； 任何区间支持必须来自同一批 bank/replicate 下标上的真实配对 bootstrap 差值， 不许拿两条边际 CI 的端点相减。

Lead —— 警报比事件早多少

Lead = D* − D_g，以优化步计。没有事件或没有警报，永远不得静默变成 0 提前量 —— 预注册要求把 early / simultaneous / late / missed / no-event 分开记。

一句话：警报响了，事件从来没被测出来过，所以提前量无从谈起。 三个失败不是同一种失败 —— D* 是仪器失败，D_g 是证据强度失败， Lead 是被前两者连坐。下面逐个拆。

03D* 为什么失败：这条判据在结构上不可能触发

不是「测了，没有脱钩」。是「这条判据在任何数据上都不会响」。

D* 的窗口要求两端都有配对完整的 spec。而一个 spec 算「完整」的条件是 （scripts/v4_decoupling_report.py:165）：它的每一张图都同时有 score 和 verdict。

每个 checkpoint 是 256 张图 / 64 个 spec = 每 spec 四张， 而 known_score_images 只有 64 —— 平均每 spec 一张有分数。 四张里有三张没有分数，于是没有任何一个 spec 能算完整。

这属于本项目反复出现的同一个失败族：一条不可能触发（或不可能失败）的判据。 记录在案的同类还有 §0.26 那条离零假设 2.6% 的证伪线、 §0.33 那条被 0.034% 跨过的边界、以及四个 generate 格子上 load_x 1.00–1.09 的「负载不变性」。 共同点是：判据写下来的时候没有人问它能不能失败。

05Lead 为什么失败：缺的是分子，不是分母

这一节很短，因为结论很简单，但方向常被记反。

Lead = D* − D_g。D_g 有（点标记意义上），D* 完全没有。 所以 lead.status = "no_event"，lead_steps = null。 报告另外留了一个 point_only_lead 字段，它的 alarm_step 是 16 / 24，但 event_step 依然是 null， point_only_lead_is_supported = false。

这是本项目最容易被写错的一句话。 「Lead 拿不到」听起来像「梯度里没看到东西」， 实际相反：梯度里看到了东西，是行为侧的尺子坏了。 按预注册，no-event 必须单独记，不得静默变成 0 提前量。

06绕过仪器缺陷之后，数据本身说了什么

下面这一段全部是替身计算：用 checkpoint 均值代替配对 spec bootstrap。 它不是注册判决，永远不能当注册判决用。但它能回答「如果尺子没坏，会看到什么」。

形状真的出现过。 naive 在窗口 (24, 40) 命中，rfo_gold 在 (16, 32) 和 (24, 40) 命中 —— 内部分数上升、外部正确率不动，这正是 D* 的定义。然后它塌了： 最后一个窗口 (48, 64) 两臂分别是 -0.0495 和 -0.0651。

这个数不能当结果用，四条理由，每一条都单独致命

  1. 事件端是替身。 注册判决要求配对 spec bootstrap，那个恒为 null。 用 checkpoint 均值代替它，等于换了一个不同的估计量。
  2. 警报端没有区间支持。 所有配对 CI 跨 0，预注册明文不认点标记。
  3. 两臂同时出现。 naive 和 rfo_gold 都命中 —— 产生它的不是两臂之间的对比，而臂间对比正是论文主张所在。
  4. 单 seed、重复看了七个窗口、无多重校正（报告自带 multiple_looks_adjusted: false、exploratory: true、两臂 status: descriptive）。而且事件之后就反转了。

07唯一扎实的一条：外部正确率一步没动

但这是必要条件，不是结论。「外部不动 + 内部上升」才是脱钩； 「外部不动」单独成立，同样和「训练什么都没学会」相容。 另外要说清楚：平的是判别阶梯的正确率，不是训练目标本身。
