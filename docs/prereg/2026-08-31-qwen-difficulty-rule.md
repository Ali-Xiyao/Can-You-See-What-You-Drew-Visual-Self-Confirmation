# 预注册：Qwen 判分下的难度选择规则

**写于 2026-08-31，在查看任何 Qwen 判分的 p 之前。**
动机：§12 查明 existence 的 `in_band` 判定是赢家诅咒——四档扫描里唯一落在带内的
一档只差 0.019 出带，held-out 实测 0.645。规则是在看过数之后被默认接受的，
所以这次先写死。

## 1. 主判据用哪个 gold

**主判据 = 场景匹配**：Qwen 报告的物体清单（shape × color × size 的多重集）
与 scene spec 的多重集完全相等，则 `image_correct = True`，否则 False。
一条规则通吃三族，不含任何否定命题。

`build_gold_atoms` 的旧逐族原子在 Qwen 检测下**同时报告一份**，仅作为与 §10
的对照，不参与任何门限判定。

## 2. 难度旋钮的接受判据

对每个 (family, objects_per_scene) 单元：

1. 用 Wilson 区间估计 p 的 95% CI（n ≈ 64/单元）。
2. 选择天花板 `C(p) = (1 - (1-p)^K) - p`，K = 4。
3. **接受条件：CI 两端映射过去的 `C(p)` 都 ≥ 0.35。**
4. 满足条件的单元中，取 `C(p̂)` 最大的那个。
5. **没有单元满足 → `knob_exhausted`**，走能力地板报告，不得改判据抢救。

用天花板而不是 p 的固定带 [0.25, 0.55] 作为判据，是因为天花板才是这个旋钮
真正要保证的量；固定 p 带在 n=64 时会把 CI 要求压到 p̂ ∈ [0.37, 0.43]，
窄到几乎必然触发 knob_exhausted，那是判据本身的产物而不是数据的性质。

## 3. 事先声明的失败模式

以下情况**不构成**改规则的理由，只构成如实报告的理由：

- 所有单元都 `knob_exhausted`
- 主判据（场景匹配）下 p 远低于旧的逐族原子判分
- 三族之间无法找到共同的旋钮档位

## 4. 判分器不确定性

Qwen3-VL-8B 为主判分器。InternVL3.5-8B 独立判一遍，每张图带
`verifier_agreement` 标记。**主结果用全部样本，不按一致性过滤**（过滤会系统性
剔除难图，污染族间对比）。一致子集上的复算作为稳健性检验并列报告。

## 修订 v2 —— 2026-08-31，晚于首批 Qwen 判分数字

**v1 原文保留在 `2026-08-31-qwen-difficulty-rule.v1.md`，不改动。**

### 改了什么

主判据从「shape × color × size 多重集匹配」改为「**shape × color 多重集匹配**」。
尺寸移出 gold，作为单独报告的维度。

### 为什么这不是 post-hoc 救场

两条理由都不依赖 v1 跑出来的数字，在写 v1 时就已成立，是搬运常数时的疏漏：

1. **`SIZE_BOUNDARY_PX = 95` 是给参考渲染器定的常数。** 生成图是带透视的照片式渲染，
   物体的像素尺寸取决于它离相机多远，不只取决于它「大不大」。前景的小苹果可以比
   背景的大碗占更多像素。绝对像素阈值在这类图上没有意义。
2. **项目已经排除过 absolute size。** STATUS「锁定的选择」：
   `排除 | absolute size | 生成覆盖 0.20 / observation 0.60，与词汇无关`。
   它被排除出问题族，却经由 `DetectedObject.size` 留在了 gold 里，是内部不一致。

**相对尺寸**（「两个杯子里大的那个」）不受影响，在单张图内部是良定义的；
失效的只有绝对的 small/large 标签。

### v1 判据下的结果，如实记录

| 打分 | p | C(p), K=4 | 预注册判据 |
|---|---|---|---|
| Qwen + 场景匹配**含尺寸**（v1 主判据） | 0.107 | 0.258 | **不通过** |
| Qwen + 场景匹配**不含尺寸**（v2 主判据） | 0.253 | 0.436 | 通过 |

v1 的不通过结果保留为记录。v2 判据下的 0.253 是**在促成这次修订的同一批数据上**
算出来的，因此**不作为确认证据**；确认须在未参与本次决定的数据上完成——
即正在跑的可核验自然场景探底。

### 未改动的部分

第 2 节的接受判据（Wilson CI 两端的 C(p) 均 ≥ 0.35）、第 3 节的失败模式声明、
第 4 节的判分器不确定性处理，全部按 v1 执行。

### 第 4 节的执行方式已细化（不改判据）

判分器不一致的样本**不做稳健性子集，改为三级升级裁定**，产出 100% 覆盖的单一金标准：

1. Qwen 与 InternVL 物体清单一致 → 采信
2. 不一致 → 裁剪到争议物体附近放大，做一次定向复问
3. 仍不一致 → 人工裁定

论文报告各级占比。理由：判分器分歧集中在难图，而难图正是选择实验唯一有信号的地方，
按一致性过滤会同时抽掉信号并污染族间对比。
